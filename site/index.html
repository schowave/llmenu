Pick a model. Start your agent.

llmenu reads the models from your LiteLLM gateway, shows price, context and benchmarks side by side, starts Claude Code, Codex CLI or GitHub Copilot CLI with the one you choose, and wires it into pi and opencode.

Install llmenu brew install --cask schowave/tap/llmenu

Choose, don't guess.

Dozens of models from several providers, aliases like claude-opus-latest, prices that differ by a factor of fifty. The menu puts what matters in one table, sorted by quality or price.

One gateway, five tools.

Each tool wants the gateway configured its own way. llmenu does the wiring: some tools it starts with the chosen model, others get the gateway's models, limits and prices written into their config. llmenu sync keeps them up to date.

See what you spend.

The menu and Claude Code's status line show the budget of the key in use, yours or the project's, and how much of it is gone.

  • One gateway key per project or cost centre, switched with llmenu project.
  • Bind a project to a folder once, and every start in it uses that key.

Your configs stay yours.

Keys in the keyring

macOS Keychain, Windows Credential Manager or Secret Service. Never in config files or process arguments, and only sent to the gateway they were stored for.

Nothing overwritten

~/.claude, ~/.codex and ~/.copilot stay untouched. In pi and opencode only llmenu's own provider entry changes, and a backup is kept.

Scriptable

llmenu list --json, "$(llmenu)" in any script. Without a terminal nothing ever waits for input. One binary for macOS, Linux and Windows.

Install it.

You need a LiteLLM gateway, its URL and an API key. llmenu does not talk to model providers directly. The benchmark key from Artificial Analysis is free.

brew install --cask schowave/tap/llmenu
scoop bucket add schowave https://github.com/schowave/scoop-bucket
scoop install llmenu
go install github.com/schowave/llmenu/cmd/llmenu@latest

Then

llmenu setup     # gateway URL and key, your tools, default models
llmenu claude    # pick a model and start Claude Code
llmenu bench     # optional: benchmark scores for the menu

Or download an archive with signed build provenance from the releases page.
